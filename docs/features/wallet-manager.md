# Wallet Manager Mini App

Similar to Money Lover, we will build a simple wallet manager mini app. The main features include:

- Create, read, update, delete (CRUD) wallets
- Each wallet has a name, balance
- Users can have multiple wallets
- Simple UI to display wallets and perform CRUD operations
- Users can add transactions to wallets
- Each transaction has an amount, type (income/expense), date, and description
- Users can edit and delete transactions, which will update the wallet balance accordingly
- Able to transfer money between wallets, which creates corresponding transactions in both wallets
- Display transaction history for each wallet
- Calculate and display total balance across all wallets
- Filter transactions by date range and type
- Responsive design for mobile and desktop
- Widget to show balance, recent transactions for global overview.
- Pipe chart to visualize income vs expenses

User stories and test cases will be defined for each feature to ensure proper functionality and edge case handling.
